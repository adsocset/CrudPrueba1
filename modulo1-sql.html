Módulo 1: Diseño de Base de Datos

Antes de programar, necesitamos un lugar donde almacenar la información. Utilizaremos SQL Server.

Paso 1.1: Crear la Base de Datos

Abre SQL Server Management Studio (SSMS) y ejecuta el siguiente script:

CREATE DATABASE ColegioADSO;
GO

USE ColegioADSO;
GO

-- Tabla de Estudiantes
CREATE TABLE Estudiantes (
    Id INT PRIMARY KEY IDENTITY(1,1),
    Nombres NVARCHAR(100) NOT NULL,
    Apellidos NVARCHAR(100) NOT NULL,
    Documento NVARCHAR(20) UNIQUE,
    Email NVARCHAR(100),
    FechaRegistro DATETIME DEFAULT GETDATE()
);
