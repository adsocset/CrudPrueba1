Módulo 2: Creando el Proyecto en Visual Studio

Utilizaremos la última tecnología de Microsoft. Sigue estos pasos cuidadosamente.

Paso 2.1: Nueva Plantilla

  1. Abre Visual Studio 2026.
  2. Selecciona "Crear un nuevo proyecto".
  3. En el buscador escribe: ASP.NET Core Web App (Model-View-Controller).
  4. Importante: No elijas "Blazor" ni "Web API" para este curso, necesitamos MVC.

Paso 2.2: Configuración

  • Nombre del proyecto: GestionEscolarADSO
  • Ubicación: C:\ProyectosADSO\
  • Framework: .NET 8.0 (LTS) o superior.
Consejo del Instructor: Asegúrate de marcar la casilla "Enable Docker" solo si tu computador tiene Docker instalado. Para este curso, déjala desmarcada para simplificar.
