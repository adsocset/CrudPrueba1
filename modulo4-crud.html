Módulo 4: Generando el CRUD (Scaffolding)

Este es el paso mágico. Vamos a usar la herramienta de "Andamiaje" (Scaffolding) para que Visual Studio escriba el código C# por nosotros.

Paso 4.1: Crear el Modelo

En la carpeta Models, crea una clase llamada Estudiante.cs y define las propiedades igual que en tu base de datos.

Paso 4.2: Agregar Controlador

  1. Clic derecho en la carpeta Controllers.
  2. Selecciona Agregar > Controlador.
  3. Elige: Controlador de MVC con vistas, usando Entity Framework.
  4. En "Clase de modelo", selecciona Estudiante.
  5. En "Clase de contexto", haz clic en "Nuevo contexto" y ponle de nombre ApplicationDbContext.
  6. Haz clic en Agregar.

¡Felicidades Aprendiz!

Has creado exitosamente una aplicación web completa. Presiona F5 y navega a /Estudiantes para ver tu aplicación funcionando.
